🚀 Node.js, Express.js & EJS – Learning Project

This repository contains my backend learning journey where I built a basic web server using Node.js, Express.js, and EJS templating engine from scratch.

📌 About the Project

I created this project to understand:

  How backend servers work

  How routing is handled in Express

  How EJS helps in rendering dynamic HTML pages

  This project is part of my learning as a BCA student and beginner backend developer.





  🛠️ Technologies Used

   Node.js

   Express.js

   EJS (Embedded JavaScript)

   ✨ Features Implemented

Created server using Node.js

Used Express.js framework

Configured EJS as view engine

Rendered .ejs files using res.render()

Organized project using views folder

Displayed headings, paragraphs & image via EJS

Implemented multiple routes:

/ → Home page (EJS rendered)

/about

/home

/profile

/papaya

Server running on localhost:3000

Auto-restart server using nodemon
